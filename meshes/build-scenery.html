meshes/scene….glb

The country the race runs through: the giant mushrooms, and the farms. Every one of these is put together out of plain primitives the way the rest of the library is - smooth shaded, coloured in the vertices, sized in world units so nothing needs scaling into place - and the faceting you can see is the geometry's, not the shader's.

The maps are not in these files. A glb in meshes/ carries no images at all: each prop declares what it wears in meshes/maps.js, and the game loads those PNGs out of meshes/tex/ by name and hands them to the material. So what goes in a file is geometry, vertex colour and a uv - one box-projected onto every part by boxUV() - and the surface arrives separately. A prop whose manifest entry is empty draws with the game's own material and no maps, exactly as it always did, which is what makes converting the library one piece at a time possible.

The colour here is the colour out there, out of the same jar (meshes/palette.js) the game reads. Open this page from the folder that serves the game and press a button, and the file is written over the one of the same name; nothing is downloaded and nothing has to be moved.
