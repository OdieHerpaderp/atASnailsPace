meshes/snail.glb

The snail, built out of the same numbers the game has always built it from. Open this page from the folder that serves the game, press write snail.glb, and save the file over meshes/snail.glb.

The names matter: the game finds the parts it animates by name - bodyG, headG, shellG, stalk0, stalk1, footM - and the ones it recolours by the name of their material - body, foot, shell, stalk. The animation moves every part from the pose set here, so the model can be reshaped freely. The foot is the one mesh whose vertices are rewritten every frame, so it must stay a single mesh. The eyes and the smile keep their own dark material, which the game leaves alone.

The head's own ball is not to be touched. It is an ellipsoid of radius 0.112 scaled 1.00, 0.97, 1.02, and build-face.html and build-hat.html both put every one of their pieces against those three numbers and the frame headG is at. Moving the head up the neck is free and making it bigger is free too — HEAD_SCALE is headG's own scale and the whole wardrobe comes up with it, because every one of those sixteen files hangs off that node. Changing the ball's own radius is the change that is sixteen files.

The shell is not built here - it is build-shell.html, which winds the same logarithmic coil three times over, once for each whorl the game hands out.
