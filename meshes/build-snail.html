meshes/snail.glb

The snail, built from the same numbers the game used to build it in code. Open this page from the folder that serves the game, press write snail.glb, and save the file over meshes/snail.glb.

The names matter: the game finds the parts it animates by name - bodyG, headG, shellG, stalk0, stalk1, footM - and the ones it recolours by the name of their material - body, foot, shell, stalk. The animation moves every part from the pose set here, so the model can be reshaped freely. The foot is the one mesh whose vertices are rewritten every frame, so it must stay a single mesh. The eyes and the smile keep their own dark material, which the game leaves alone.

The shell is not built here - it is build-shell.html, which cuts the same dome three times over, once for each whorl the game hands out.
