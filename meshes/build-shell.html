meshes/shell-….glb

The three whorls the snail wears: shell-bands, shell-swirl and shell-spots. One is a round dome with a spiral furrow cut into it and the pattern painted on in vertex colours - the same dome three times over, so the three files can never drift apart in shape. Open this page from the folder that serves the game and save each one over the file of the same name.

Nothing here is named for the game to find: it loads each file, takes the first mesh in it and keeps the geometry, handing out its own material and its own colour. So the mesh name is only for the person reading the folder.

snail.glb carries a shell of its own, cut from this dome, and the game swaps in one of these three the moment a racer is built.
